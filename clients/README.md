# Clientes

Configurações e diferenças de cada cliente, organizadas em `clients/<cliente>/`,
sem secrets ou dados pessoais reais. A estrutura reutilizável será definida em T006.

Como usar: quando houver um cliente configurado, seguir o README da sua pasta
para utilizar as automações e integrações correspondentes. Valores de secrets
ficam em `.env`; `.env.example` lista apenas os nomes e suas descrições.

Como testar: validar a configuração com cenários e dados fictícios, seguindo
os testes das automações e integrações utilizadas. Ainda não há clientes configurados.
