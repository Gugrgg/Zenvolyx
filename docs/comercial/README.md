# Comercial

Espaço para propostas e materiais de vendas. Agentes só devem consultar esta
pasta quando a tarefa exigir.

Foco atual (D025): clínicas odontológicas, com a oferta "Sistema de Atendimento,
Qualificação e Agendamento com IA para Clínicas Odontológicas". Tarefas comerciais:
seção "Fase comercial" do [TASKS.md](../../TASKS.md), de B001 em diante. Listas de
prospecção e contatos de pessoas ficam fora do repositório.

Como usar: criar ou atualizar materiais conforme a demanda, sem incluir secrets
ou dados pessoais reais em exemplos.

Como validar: revisar o conteúdo e os links antes de compartilhar.
Não há código executável nem testes automatizados nesta pasta.
